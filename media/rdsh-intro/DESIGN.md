# 紹介動画の新版

参考: <https://x.com/timkochjar/status/2092278549679886507>

実際の参考映像を12の時点で確認。白い空間、青い反射面、短いコピー、
UIのクローズアップ、点群の立体、文字のマスク表示を参考にする。
参考映像の画像・音楽・プロダクト画面を完成動画には使わない。

背景 #fafbff、文字 #172232、主色 #075cbe、反射 #93c9ff、
薄青 #d9e9fb、金属 #cad5e2。Instrument SansとNoto Sans JPを使う。
太い見出しや章番号を常設せず、各場面で一つの対象に視線を集める。

52秒・1920×1080・60fps。文字を見せ、UIへ近づき、結果を見せる。
CSSの立体移動とThree.jsの反射するリボンを使う。
括弧付きの注記と長い常設字幕を外し、測定条件とデモ表示は簡潔に残す。
すべて既存の点検済みデモ素材を使用し、個人情報の制約を維持する。

| 秒 | 場面 |
| --- | --- |
| 0–2 | 小さな導入コピー |
| 2–6 | 青い立体リボンとrdsh |
| 6–9 | 文字のマスク表示 |
| 9–15 | 白いCLI画面の検索・トークン見積もり |
| 15–19 | 起動中央値と点群 |
| 19–22 | 進捗への切り替え |
| 22–30 | 実UIのタスクから指標へカメラ移動 |
| 30–33 | 点群と回答への切り替え |
| 33–40 | 実UIの回答と保存 |
| 40–46 | スマホ表示 |
| 46–52 | リボンと導入への案内 |
