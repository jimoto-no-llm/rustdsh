# Harness icons

The chart marks each harness with its logo. The PNGs in `site/public/bench/icons/`
are generated from the SVGs listed below; `render.py` re-tints and re-renders them.

| Harness | Source | Notes |
| --- | --- | --- |
| DSH | Simple Icons `deepseek` | DeepSeek mark |
| Codex CLI | Simple Icons `openai` | OpenAI mark |
| Claude Code | Simple Icons `claudecode` | Claude Code mark |
| Gemini CLI | Simple Icons `googlegemini` | Gemini mark |
| opencode | Simple Icons `opencode` | opencode mark |
