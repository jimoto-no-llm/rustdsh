## 0.13.1 — 最初の一歩を「選ぶだけ」にする

- `rdsh doctor` の末尾に「次の一手」を出し、対話端末では **Web UI かターミナルか** を 1/2 で選べるようにしました（Enter だけならデスクトップセッションの有無で決めます）。
- セットアップ手順書 `docs/SETUP.md` を追加しました。AI エージェントにそのまま読ませる前提で、接続先を 1 つ選ぶ（OpenAI・OpenCode Go・Command Code・Ollama）→ 推奨プラグイン → 起動までを 1 ステップずつ並べています。
- `rdsh setup --web` が、端末のない環境（AI エージェント経由・ランチャーからの起動・`ssh -T`）でもブラウザを開くようにしました。

## 修正

- `rdsh setup --web` が端末なしではトークン引き渡しファイルを手で貼る手順になっていました。デスクトップセッションがあれば必ず画面を開き、画面のない機械では従来どおり URL だけを出します（`RDSH_SETUP_OPEN=0` で抑制できます）。
