## 0.5.2 — 同期スクリプトの自己更新

- **同期スクリプトの自己更新**: 毎日の自動更新（`sync-dsh.sh`）が作業を始める前に、`main` にある最新のスクリプトで自分のインストール済みコピーを置き換えるようにしました。モデルカタログの同期など日次処理の修正が、手動更新を待たずにすべてのマシンへ届きます。`RDSH_SYNC_SELF_UPDATE=0` で1回だけ無効化でき、git checkout 内のコピーは変更せず、取得先に到達できない場合やシェルスクリプトでない内容が返った場合は現在のコピーを維持します（`docs/AUTO-UPDATE.md`、#697）。
- **成果物プレビューの境界修正**: ダッシュボードの成果物プレビューが、大きな成果物の表示量を制限し、新しいリクエストに置き換えられた古いプレビューを破棄するようにしました。あわせて、切り詰め時に UTF-8 のマルチバイト文字を分割しない、通常ファイル以外は 415 で拒否する、URL 内の認証情報を正規表現に依存せず伏せる、という修正を入れています。ダッシュボードテストとブラウザ E2E で回帰を検出します（#698）。
- **インストーラ台帳の更新**: `release-digests.tsv` と `release-digests-windows.tsv` に公開済み v0.5.1 の各アーカイブの SHA-256 を追記し、`latest` 行を v0.5.1 へ進めました。`install.sh --from-release` と自動更新は v0.5.1 を導入します（#695）。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。導入手順は 0.5.1 から変更ありません。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2**、**0.2.1-alpha.1**、**0.2.1-alpha.3** のランタイムを認識）。
- 移行作業は不要です。`rdsh.json` の既存キーや既定値は変わりません。同期スクリプトの自己更新は `sync-dsh.sh` 側の既定動作で、無効化は `RDSH_SYNC_SELF_UPDATE=0` です。
- **既知の制約（自己更新のブートストラップ）**: 自己更新の仕組みは 0.5.2 以降のコピーで有効になります。0.5.1 以前の `sync-dsh.sh` をインストールしたマシンは、この改善を一度だけ手動で受け取る必要があります（`rdsh update auto on` の再実行、または `sync-dsh.sh` の更新）。1回更新した後は、以降の同期スクリプトの修正が自動で届きます。
- ソースからビルドする場合は Rust 1.85 以上が必要です（配布バイナリの利用に Rust は不要）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同リリースの `install.ps1 -FromRelease` を使用してください。
