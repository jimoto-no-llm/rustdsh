## 0.14.0 — 成果物ファイルを直接保存できるように

### 追加

- `rdsh files list` / `rdsh files get` を追加しました。セッションが `present` で宣言した成果物（ファイル）を一覧し、コピーして保存できます。宣言されていないファイルは読みません。
- `rdsh serve` に `GET /api/files`（一覧）と `GET /api/file?path=<path>`（ダウンロード）を追加しました。ブラウザから直接保存できます。

### 修正

- `rdsh-mcp-exposure` を DSH **0.2.1-rc.3** の一式で動くようにしました。検証済みリリースの矩陣に rc.3 と rc.4 を追加し、`devDependencies` を揃え、3 言語のエラーメッセージも更新しました。
- Windows で Web ホストが異常終了した後の常駐運用向けに、回数制限とバックオフを持つ監視スクリプトを追加しました。正常終了と Ctrl+C では再起動しません。
- Windows の Node 24.15.0 で再現した TCP 接続時のネイティブクラッシュについて、修正を含む 24.16.0 以降への更新手順、再現スクリプト、診断根拠を追加しました。

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
