## 0.10.0 — 実行の信頼境界を固め、Web UI の読み込みを軽く

- 外部コマンド起動の信頼境界を強化しました。git 起動は PATH からの信頼付き解決に加えて
  `-c core.fsmonitor=false` と `GIT_CONFIG_NOSYSTEM`/`GIT_CONFIG_GLOBAL` の固定を行い、
  systemctl・npm/pnpm・`RDSH_DSH_BIN` も共通の owner/mode 検査（exec_trust）を通します。
  汎用 `PREFIX` は探索から外しました（#826）。
- `rdsh worker-scope policy` の判定側 probe path を宣言側と同一規則で検証し、
  `forbidden_paths` を読み取りにも適用しました。交差判定は forbidden 部分木を減算した
  うえで行います（#827）。
- strict 監査（`RDSH_SECURITY=1`）で dsh 本体 `lib/bin.js` の SHA256 を監査表に追加し、
  境界設置前に内容を照合するようにしました。manifest だけ一致させて bin.js を差し替える
  偽ツリーを拒否します（#824）。
- `rdsh search-web` の接続先を既定でループバックのみに制限しました。ループバック以外は
  `SEARXNG_ALLOW_REMOTE=1` で明示許可し、リンクローカルとキャリア級 NAT 帯は常に拒否します。
  `https://` 接続に対応し、ログと `--json` では接続先のパスをマスクします（#828）。
- `rdsh cloud` の JSON 入力を 128 MiB 以下の通常ファイルに制限し、読込中のサイズ増加も
  検出するようにしました（#825）。
- `RDSH_NODE_COMPILE_CACHE=<ディレクトリ>` で Node コンパイルキャッシュの出力先を指定
  できるようにしました。`0` による無効化と、既存の `NODE_COMPILE_CACHE` が優先される
  挙動は変わりません（#864）。
- 0 バイトのまま残った `.credentials.yaml.lock` を、mtime が猶予期間（5 秒）を過ぎたら
  收回するようにしました。書き込み前のクラッシュで起動がタイムアウトし続ける状態から
  自動で復帰します。PID 記録を持つマーカーの收回条件は変わりません（#865）。
- Web UI のシェル資産を Rust 側で事前圧縮（brotli q11 / gzip 6）して配信するようにしました。
  `Cache-Control: public, max-age=31536000, immutable` と `ETag` を付け、`If-None-Match`
  一致時は 304 を返します。機能は変えずに転送量が 26.6% 減り、4 資産の取得時間も
  42.4% 短くなりました（#863、#870）。切り戻しは `rdsh features off web_assets` です。
- `rdsh rustxng install` を追加しました。RustXNG の最新リリースを `~/.local/bin` へ導入し、
  サイドカーが見つからない状態で `rdsh search-web` や `rdsh rustxng start` を使うと
  自動で導入してから起動します（`RUSTXNG_SKIP_INSTALL=1` で自動導入を止められます）。
- Web 検索（search-web）を既定 ON にしました。無効化は `rdsh features off search-web` です。
  ローカル状態画面（serve）の既定 OFF と `extras.enable` の従来形式は変わりません。
- DSH の Like/Dislike と /feedback 画面（feedback 機能）を既定 OFF にしました。rdsh 固有の
  不具合が DSH 本家へ送られないようにするもので、既定では `rdsh-no-feedback` バンドルで
  無効化します。画面を戻すときは `rdsh features on feedback` を保存してからプラグインを
  導入し、DSH を再起動してください。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 必要なもの: 更新元の `dsh`（@deepseek-ai/dsh）が導入済みで PATH にあること。ソースから
  ビルドする場合のみ Rust 1.85 以上が必要です。
- 互換性: 設定・プロファイル・プラグインの移行は不要です。委譲（パススルー）の挙動は
  変わりません。検索先の既定がループバック限定になり、リモートの SearXNG を使う場合は
  `SEARXNG_ALLOW_REMOTE=1` が必要です。feedback 機能は既定 OFF になります。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
