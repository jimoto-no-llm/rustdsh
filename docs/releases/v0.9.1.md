## 0.9.1 — 必須プラグインの補完、デスクトップと設定画面の使い勝手、検索とサービスの修正

- **必須プラグインをバイナリから補完**: `rdsh plugins status|install` がバイナリ同梱のカタログ（`src/plugin_catalog.json`）を読み、プロファイルに欠けている必須パッケージを `dsh plugin --profile <name> add` で補います。`--recommended=none|all|starter|id,id` は `plugins/install.sh` と同じ選択を提供し、`--profile desktop` は `rdsh desktop install` へ転送します。`rdsh doctor` は不足しているプロファイルごとに 1 行で不足数と修正コマンドを表示します（#816）。Web プロファイルのインストールでも必須プラグインが自動で入ります（#816）。
- **デスクトップアプリの操作性**: 会話履歴のページング、ショートカット、会話検索、ダークテーマに対応しました。会話タイトルは全件取得して ✎ から名前を変更でき、プロジェクトの折りたたみ・アーカイブとシャチのアイコンを使えます（#806、#810）。macOS / Windows 向けのプラットフォーム別ビルドとパッケージ手順、CI を追加しました（#810）。
- **設定画面と Web UI**: 設定タブ「rdsh」がカード表示になり、グループを折りたためます。ローカル Web UI にはコンテキスト・実行・更新のゲージが付きます（#810）。
- **更新カード**: dsh 本体の更新も同じカードに併記し、単独でも表示します。実行中の dsh 版はホストのエントリから特定し、通知は × で閉じられ、dsh の更新はユーザー所有の prefix へ入ります（#801、#803）。
- **検索**: `rustxng` をローカル検索バックエンドとして選べ、結果は HTML ではなく JSON API から取得します（#805、#815）。
- **モデルとクラウド**: OpenCode の既存ルートを Web / TUI プロファイルへ同期できます（#813）。オプトインの swarm / sandbox CLI を追加しました（#809）。
- **修正**: 予期しない終了からの Web サービス復旧と systemd 再起動の引き渡し（#811）、読み取り側が先に閉じたときの EPIPE で panic しない静かな終了（#804）、設定カードで失われていた tokens 見出しの復元（#810）。
- **ドキュメント**: Discord コミュニティ、rdsh と dsh の違い、デスクトップの操作、TUI の初期設定、Node.js 22 の入手方法を追加・更新しました（#807、#808、#810）。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 で、v0.9.0 から変わりません。配布アーカイブと両インストーラの構成も同じです。
- 会話とモデル応答は本家 DSH のままで、互換性は v0.9.0 と同じです（ハーネスのクライアントプロトコルは Desktop **0.2.0-rc.2**、**0.2.1-alpha.2**、**0.2.1-rc.2** で確認済み）。移行作業も `rdsh.json` の変更も不要です。
- **既定のプラグイン構成が広がりました**: `rdsh desktop install` の既定セットに更新バナーが入り（#814）、Web プロファイルのインストールと `rdsh plugins install` が必須ティアを補完します（#816）。不要な場合は `rdsh plugins install --recommended=none` や `--no-<plugin>` 系のフラグで外せます。
- **設定画面の見た目が変わりました**: 設定タブ「rdsh」がカードと折りたたみに変わりました。保存される値と `rdsh.json` の形式は変わりません（#810）。
- **ネイティブ・デスクトップアプリは引き続き同梱されません**: 配布アーカイブには含まれず、`apps/rdsh-desktop` を Rust 1.85 以上でビルドしたソース実行のみです。
- **版の判定: patch**（メンテナの指示により、マージ済みの変更を 0.9.1 として速やかに公開します。`[Unreleased]` に `### Added` があるため、通常の判定規則では minor 相当です）。
- ソースからビルドする場合は Rust 1.85 以上が必要です（配布バイナリの利用に Rust は不要）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
