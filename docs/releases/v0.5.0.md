## 0.5.0 — モデルカタログ同期・多言語対応とダッシュボードの一括統合

- **モデルカタログの取得と同期**: `rdsh models` がプロファイルごとに不足しているモデル ID と古くなった表示名を読み取り専用で報告し、`rdsh models sync` が各プロバイダーの公開カタログ（`openai-codex` は `codex debug models`、無ければ `$CODEX_HOME/models_cache.json`、`kimi-coding` は認証付き `GET /v1/models`）を取り込んで `llm-pi-ai` のモデル一覧を更新します。既存エントリは削除せず、解釈できない YAML は書き換えずに必要な形を示して拒否し、更新は DSH と同じロックで原子的に行います（`docs/MODEL-ROUTING.md`）。
- **多言語対応（English／简体中文／日本語）**: CLI のヘルプ・診断・対話セットアップ、Web UI、独立ダッシュボード、設定プラグイン、外部エージェントのヘルプを `en`／`zh-CN`／`ja` で表示します。選択は `--language`、`RDSH_LANG`、`general.language`、`LC_ALL`／`LC_MESSAGES`／`LANG` の順で、既定の `auto` は未設定・未対応なら英語です。委譲する `dsh` 引数、モデル出力、JSON フィールド、ファイル、プロトコル識別子は翻訳しません。
- **ダッシュボード機能の一括統合**: 並行開発していたダッシュボード関連 PR を1本に統合しました。プロジェクト移動後の履歴保全、デバイス別権限、版付きの判断ログとプロジェクトプロファイル、プロバイダーのクォータ／再試行表示、実行停滞の保守的な診断、横断プロジェクト概要、因果タイムライン、通知の優先度付け、プロジェクト単位のディープリンク、再利用可能なワークフローレシピ、成果物プレビュー、秘匿情報を含まないリプレイ用マニフェスト、安全な状態移行などを含みます。
- **セキュリティ修正**: 未解決だった Dependabot／Code scanning のアラートを解消し、MCP 系プラグインと headless runtime の `@modelcontextprotocol/client` を修正版 2.3.1、`fflate` を 0.8.3 に固定しました。監査済みランタイムの版別照合と `RDSH_SECURITY[...]` 形式の拒否診断（未対応 runtime／差し替え検出／解決不一致）も復元しています。
- **Windows の安定性とテスト修正**: Windows のデバッグ実行で main スレッドのスタックが 1MiB 固定だったため、clap のパーサ構築中にスタックオーバーフローで落ちていました。MSVC は `/STACK:8388608`、GNU は `-Wl,--stack,8388608` で Unix と同じ 8MiB を予約します。native E2E と zstd 回帰試験も Windows の fail-closed 挙動に合わせて修正しました。
- **設定と更新まわりの修正**: 更新通知は dismiss した版を再表示しなくなり、更新失敗時は stderr の理由を保持します。設定プラグインは文字列を Unicode スカラー単位で切り詰め、Rust 側と同じ上限（`default_profile` 200／`searxng_url` 2000）を使うため `rdsh.json` を壊しません。Desktop の相対 `--plugins-dir` は解決してから使います。`rdsh logs` の英語表示退行も修正しました。
- **回答ガード**: `plugins/rdsh-answer-guard` が、応答が reasoning チャンネルだけに出力されてターンが完了したケースを検出し、1ターンに1回だけ本文としての再出力を促します（`rdsh features off answer_guard` で無効化）。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。導入手順は 0.4.0 から変更ありません。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2**、**0.2.1-alpha.1**、**0.2.1-alpha.3** のランタイムを認識）。
- 移行作業は不要です。`general.language` は今回追加される設定で、既定は `auto`（OS ロケール、未対応なら英語）です。`rdsh.json` の既存キーや既定値は変わりません。ダッシュボードの状態移行は自動化され、再適用に失敗した場合は復元用マニフェストから元データを戻せます。
- ソースからビルドする場合は Rust 1.85 以上が必要です（配布バイナリの利用に Rust は不要）。
- `rdsh models sync` のカタログ取得は `openai-codex` と `kimi-coding` に対応します。プロファイルの `llm-pi-ai` が読み取り可能なブロック形式でない場合は、書き換えずに必要な YAML を示して停止します。
- 日本語以外の回答を和訳して履歴上で置換する機能（#448）はこの版に含まれません。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同リリースの `install.ps1 -FromRelease` を使用してください。
