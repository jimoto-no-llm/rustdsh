## 0.12.0 — 同梱プラグインを全インストーラで確実に入れる

- `curl … | sh` で入れた環境に同梱プラグインが付くようにしました。従来は checkout 上でしか
  `plugins/install.sh` を実行できず、リリースの tar.gz には `rdsh` バイナリしか入っていない
  ため、設定の **rdsh** タブも更新バナーも現れませんでした。
- リリースに `rdsh-plugins.tar.gz` を追加し、`install.sh` が同じタグから取得・検証して
  `PREFIX/share/rdsh` へ展開してから同梱インストーラを実行します。展開先はランチャーが
  既に探索する場所なので、以後の `rdsh plugins install` も同じ tree を見つけられます。
- Windows の `install.ps1` も同じ経路に対応しました。従来は `-Desktop` 指定時だけ Desktop
  プロファイルへプラグインを入れており、Web プロファイルは空のままでした。
- 同梱プラグインのダイジェストは新しい台帳 `release-plugins-digests.tsv` で検証します。
  既存の `release-digests.tsv` に足すと、公開済みの旧インストーラが「未知のアセット」として
  ファイル全体を拒否するため、台帳を分けています。取得や検証に失敗してもインストール自体は
  止めず、理由と次の一手を表示します（`RDSH_SKIP_PLUGINS=1` で抑止）。
- リリース検証が `rdsh-plugins.tar.gz` を受け入れるようになりました。`plugins/` 配下に
  閉じていること、`plugins/install.sh` があること、パス traversal やリンクを含まないことを
  確認してから公開します。リリース資産は 16 点から 18 点になります。
- サブエージェントの **provider・model・reasoning effort** を設定画面から選べるようにしました。
  `plugins/rdsh-subagent-route` がプロファイルの `cordis.patch.yml` にある `tool-subagent` の
  `agentOptions` を読み書きし、DSH 自身が次の子から適用します。推奨ティア（既定 off）なので
  `rdsh plugins install --recommended=subagent-route` で入ります。
- 厳格なツール境界（`features.agent_tool_sandbox` / `RDSH_SECURITY=1`）が DSH **0.2.1-rc.3** を
  監査済みランタイムとして認識するようにしました。rc.3 では `dsh-tools` のエントリ内容が
  alpha.3 と変わり、旧アダプターのままでは委譲実行が `UNSUPPORTED_RUNTIME` で拒否されていました。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 必要なもの: 更新元の `dsh`（@deepseek-ai/dsh）が導入済みで PATH にあること。ソースから
  ビルドする場合のみ Rust 1.85 以上が必要です。Windows で同梱プラグインを展開するには
  `tar.exe`（Windows 10 1803 以降に標準搭載）を使います。
- 互換性: 設定・プロファイルの移行は不要です。`rdsh-no-feedback` を使っている場合、
  `rdsh plugins install` を再実行すると `rdsh-no-feedback-client` も一緒に導入されます。
- 同梱プラグインは**次のリリース以降**のインストーラでのみ取得されます。この版より前の
  インストーラは `rdsh-plugins.tar.gz` を知らないため、従来どおり checkout からの導入が要ります。
- 更新後は既存の rustdsh プロセスを再起動してください。設定タブと更新バナーは再起動後に出ます。
- 版の判定: minor（同梱プラグインの配布経路の追加と、サブエージェントのルート設定という
  新しい利用者向け機能が入るため。既存の設定は書き換えません）。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
