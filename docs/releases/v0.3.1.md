## 0.3.1 — ダッシュボードと導入まわりの修正版

- **Dashboard の修正**: モデルカタログのモジュールが配信・認証の両リストから漏れていたため、プロジェクト画面が 401/404 で真っ白になっていました。修正済みです。
- `rdsh serve` が stderr を閉じられると panic で落ちる問題（例: `rdsh serve 2>&1 | head -1`）を修正しました。
- `install.sh --from-release` がアーカイブ・sidecar・展開済みバイナリを TMPDIR に残す問題を修正しました。
- setup 画面の追加機能スイッチが `features.<id>` を反映せず、表示と実効状態が逆になる問題を修正しました。
- DSH web UI の設定「rdsh」に、実行中の rdsh / dsh のバージョンを表示します。
- Desktop 連携（`rdsh desktop status|install|verify`、`PROFILE=desktop ./plugins/install.sh`）を追加しました。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。導入手順は 0.3.0 から変更ありません。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2** と **0.2.1-alpha.1** を認識）。
- 移行作業は不要です。既存の `rdsh` は同じコマンドで上書き更新できます。
- 設定は `$DSH_HOME/rdsh.json` のままです。setup 画面で切り替えると `features.<id>` が明示値になります。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows は同じ Release の `install.ps1 -FromRelease` を使用してください。
