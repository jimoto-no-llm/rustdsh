## 0.12.2 — DSH 0.2.1-rc.4 への追従

- DSH **0.2.1-rc.4** に対応しました。厳格なツール境界（`features.agent_tool_sandbox` / `RDSH_SECURITY=1`）の監査済みアダプターに `dsh-tools-0.2.1-rc.4` を追加し、`rdsh-mcp-exposure` と `rdsh-llm-muse-code-subscription` の peer 範囲にも rc.4 を入れました。rc.4 の `lib/bin.js` と dsh-tools の `lib/index.js` は rc.3 と同一のため、ダイジェストは同じ値です。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 版の判定: patch。内容は DSH 0.2.1-rc.4 への追従（互換修正）のみで、利用者向けの新機能は含みません。
- 互換性と移行の要否はこの準備 PR で確定してください。破壊的変更は CHANGELOG とこのノートで必ず明示してください（0.x の間は minor で表現してかまいません）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
