## 0.17.0 — DSH 0.2.2-rc.5 全面対応・コア隔離境界の強化・RustXNG ミラー検証取得

- **DSH `0.2.2-rc.5` と `@earendil-works/pi-ai` `1.6.0` 対応**: 保護付きツール委譲アダプターと初期セットアップ自動導入を `0.2.2-rc.5` へ対応させ、Dashboard（`plan-native` 監査面・予算制御面）、`rdsh-budget-guard`、`rdsh-mcp-oauth`、`rdsh-ptc-catalog`、`rdsh-session-cleanup`、`rdsh-llm-native`、`rdsh-compaction`、`rdsh-subagent-optimizer`、およびオフライン headless 候補ランタイムビルダーを新契約へ拡張しました（監査記録: [dsh-rc5](https://github.com/jimoto-no-llm/rustdsh/blob/main/docs/evidence/dsh-rc5/README.md)）。
- **コア隔離境界と認証情報の保護強化**: `--share-file` 指定時に `features.agent_tool_sandbox = false` が明示されている場合は起動を拒否するようフェイルクローズ化し、カレントディレクトリの暗黙プラグイン参照廃止、Windows `.cmd` 引数の `%` 展開防止、Windows 資格情報ファイルの `rename` 前 ACL 制限、および `native_oauth` の `O_NOFOLLOW` 単一 FD 検査を追加しました。
- **RustXNG の SHA-256 検証統一と GitLab ミラー連携**: 初回自動導入を必須 SHA-256 検証経路へ統合し、GitHub 上の配布元へ到達できない場合でも GitLab ミラー Releases から `.sha256` サイドカー照合付きで取得できるようにしました。あわせて通知状態ファイルの `0600` アトミック更新と chunked HTTP 応答のバイト単位解析を追加しました。
- **TUI フォールバックと Web UI 更新通知の改善**: ローカル `tui` プロファイル未作成環境で `rdsh tui` が組み込み Rust TUI へ自動フォールバックするようにし、Web UI 更新通知を 1 枚の多言語カード（日・英・中）に統合してイベント時刻 `at` 単位の閉鎖保持と `dsh` dist-tags 順序比較に対応させました。
- **品質・依存衛生の改善**: `native_compaction` の飽和演算化と孤児 `ToolResult` 不動点再検査、依存パッケージ脆弱性の解消、回帰・リリーステストのロケール非依存化、および複数行 CHANGELOG 項目のリリースノート出力欠落修正を含みます。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 版の判定: minor（DSH `0.2.2-rc.5` 対応拡張、GitLab ミラー検証取得フォールバック、TUI 自動フォールバックなど利用者に見える機能追加と境界強化を含むため）。
- 設定ファイルの移行作業は不要ですが、以下のセキュリティ境界変更にご注意ください。
  - `rdsh.json` で `features.agent_tool_sandbox = false` を明示したまま `--share-file` を指定するとエラー終了します（`rdsh features on agent_tool_sandbox` で有効化するか `--share-file` を外してください）。
  - `rdsh desktop` のプラグイン探索はカレントディレクトリを暗黙参照しなくなりました。開発ツリーを指定する場合は `--plugins-dir <checkout>` または `RDSH_PLUGINS_DIR` を明示してください。
- `rdsh-mcp-exposure` は上流 `0.2.2-rc.5` で旧モード制御契約が廃止されたため、引き続き `0.2.0-rc.2` 専用です。
- 更新後は既存の `rustdsh` プロセスおよび Dashboard を再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
