## 0.2.1 — 設定・画面の使いやすさとローカル処理の改善

- Claude Code／CodexからDSHへ移行する日英のガイドを追加。本家DSHの導入、モデル接続、既存の指示ファイルの再利用、最初の会話と元の環境へ戻る手順を案内します。
- 初回設定でAnthropic・OpenAI・DeepSeekのAPIキーを選択可能に。設定の文言・保存状態・失敗時の再試行を整理。複数行の入力や他の項目の未保存編集を保持し、スマホ幅でも設定を読みやすくしました。
- Dashboardは変化した領域だけを更新し、入力中の質問・フォーカス・カーソルを保持。非表示時のポーリングを止め、切断中も期限切れ表示を更新します。
- 同じ出力を保ったまま、単独の`--version`、ASCIIの切り詰め、該当なしの検索を高速化。再現手順・全測定値・実画面のPNG/GIFを[ベンチマーク記録](https://github.com/jimoto-no-llm/rustdsh/blob/main/docs/BENCHMARKS.md)に公開します。
- GitHubの導入案内・Issueフォーム・配布手順を整理。5種類のビルドとSHA256を揃え、アップロード後の再検証が済んでから公開します。

## 更新前に確認

- 設定・履歴の移行は不要です。既存のDSHへの委譲、未知の設定項目、明示的な認証取り込みを保持します。更新後は既存のrustdsh・Dashboard・DSH Webプロセスを再起動してください。
- ローカルの`tokens`／`prune`とプロジェクトMCPは、本家DSH・DSHのアカウント・モデル用APIキーなしで使えます。MCPの画面はNode.js 22+とソースcheckoutが別途必要です。ReleaseアーカイブにはRust CLIを収録しています。
- 移行元の会話履歴・resume ID・hooks・MCP設定は自動変換しません。Claude Codeの契約・ログインの直接取り込みは未対応です。現行のモデルツールは共有ファイルの読み取り専用で、コード編集やホストのテスト実行までは置き換えません。[READMEの移行案内](https://github.com/jimoto-no-llm/rustdsh/blob/main/README.ja.md#はじめに)で対応範囲と復旧手順を確認してください。
- Linux x86_64（glibc／musl）、macOS（arm64／x86_64）、Windows x86_64用バイナリを配布します。ネイティブ`search`はWindowsでは起動を拒否します。WSLで利用してください。トークン数は概算で、モデル固有の請求値ではありません。
- rustdsh経由のagent実行は引き続きLinux x86_64・bubblewrap・prlimit・監査済みDSH 0.2.0-rc.2／0.2.1-alpha.1が必要です。未対応環境では起動を拒否します。外部CLIの認証情報は自動取り込みしません。
- 高速化の測定はLinux/WSLの合成入力とブラウザー描画です。モデルの応答時間や実ユーザーのINPを測った結果ではありません。改善しなかったケースも含め、元データを掲載しています。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windowsは同じReleaseの`install.ps1 -FromRelease`を使用してください。

```powershell
$f = Join-Path $env:TEMP "rdsh-install.ps1"
Invoke-WebRequest -Uri https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.ps1 -OutFile $f -UseBasicParsing
powershell -ExecutionPolicy Bypass -File $f -FromRelease
```

導入後は`rdsh --version`が`rdsh 0.2.1`となることを確認してください。
