## 0.3.2 — 検索・計算・CLI まわりの修正版

- **セッション検索の修正**: `context search` が `CI`・`UI`・`Go` のような2文字のASCII語でも結果を返すようになりました。日本語2文字（bigram）への加点はこれまでどおりです。
- **Web検索の修正**: `search-web` が、タイトル・URL・snippet に correction 語が含まれるだけの正常な検索結果を除外しないようになりました。
- `tokens`・`compute`・`serve` の `chars` が UTF-8 バイト数ではなく文字数になりました（日本語3文字の場合は `3`、以前は `9`）。
- `rdsh-compute` が worker の stdin の EPIPE を処理し、Node ホストごと終了しないようになりました（失敗時は JS 計算へフォールバックします）。
- 委譲時に `PATH` 上の実行できない `dsh` や Node の候補をスキップするようになり、`Permission denied` で停止しなくなりました。
- `rdsh headless "run the tests"` が、位置引数のプロンプトを `--profile` 明示時と同様に転送するようになりました。
- `--dump-default-config` と `--dump-config-schema` が `--dump-config` に誤変換されず、そのまま upstream の `dsh` へ渡るようになりました。
- `rdsh compact` が改行をトークン予算にカウントし、余分な末尾改行を付加しないようになりました（予算 8000／1／0 の回帰テスト付き）。
- 認証情報の鍵ローテーションで `refs` を重複追記せず置換するようにし、すでに重複したファイルは1件に修復されるようになりました。
- Dashboard の受け入れチェックが、`.env.example` のような無関係な禁止ファイルによって `invalid_input_path` で停止しなくなりました。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。導入手順は 0.3.1 から変更ありません。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2** および **0.2.1-alpha.1** を認識）。
- 移行作業は不要です。既存の `rdsh` は同じコマンドで上書き更新できます。
- 設定は `$DSH_HOME/rdsh.json` のままです。今回の修正でキーや既定値の変更はありません。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同リリースの `install.ps1 -FromRelease` を使用してください。
