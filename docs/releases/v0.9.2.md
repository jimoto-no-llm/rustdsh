## 0.9.2 — dsh 本体のアップデートを確実に、更新通知を一回で

- 「dsh 本体のアップデート」を押しても更新が実行されず、通知が繰り返し表示される
  不具合を直しました。`~/.local/opt` 配置（install.sh の手動配置）の dsh も、
  書き込める場合は所有 prefix 経由で更新します。失敗時はバックアップから復元し、
  sync 全体（rdsh の更新を含む）は止まりません。
- `rdsh serve` のダッシュボードを、初めてでも迷わない言い回しと操作に刷新しました
  （接続手順、状態の確認、セッション一覧の見せ方）。
- DSH の回答画像がテキスト行の残り幅に押し込まれるレイアウト崩れを直しました
  （DSH 0.2.0-rc.2 の Web UI で確認）。

## 更新前に確認

- 対応プラットフォーム: Linux（x64、x64-musl）、macOS（arm64、x64）、Windows（x64）。
- 必要なもの: 更新元の `dsh`（@deepseek-ai/dsh）が導入済みで PATH にあること。
  ソースからビルドする場合のみ Rust 1.85 以上が必要です。
- 互換性: `dsh` 0.2.0-rc.2 世代と組み合わせた動作を確認済みです。設定・プロファイル・
  プラグインの移行は不要です。委譲（パススルー）の挙動は変わりません。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
