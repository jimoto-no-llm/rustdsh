# rustdsh v0.2.0

セキュリティ修正と、最新mainに入ったDashboard・セッション管理の改善を含みます。

## 更新前に確認

- **rustdsh経由のagent実行はLinux x86_64のみ対応**。bubblewrap、prlimit、対応するNode.js、DSH **0.2.0-rc.2** が必要です。未対応環境では無保護で実行せず起動を拒否します。macOS・Windows用binaryも配布しますが、agent実行は使えません。
- agentツールは、人間が `--share-file <relative-path>` で共有したファイルだけを読み取れます。秘密情報・ホストへの書き込み・ネットワーク・権限拡大を伴うツール操作は許可しません。隔離内の使い捨て `/tmp` は利用できます。
- 外部Codex/opencodeの認証情報は自動取込しません。必要なら `rdsh auth --import --provider <provider>` で明示的に取り込みます。
- 修正はこのbinaryから起動した新規rustdshプロセスに適用されます。既存プロセスは再起動してください。元DSH・OpenCode・Dashboardの明示的な元CLI直接実行は、このlauncherの保護対象外です。

## 含まれる改善

- プラグインAPIの認証、設定保存、ファイル読み取り、guard、agentツールの実行境界を強化。
- インストール・自動更新でSHA256を確認し、全OSの配布物が揃ってからReleaseを公開。
- 最新mainのセッションtokenキャッシュ修正、DashboardのCLI連携・復元・質問/返信・費用/予算・履歴backup・段階更新を同梱。
- 更新バナーのdismiss状態を保持。更新処理が成功した環境で表示され、全利用者への一斉Push通知ではありません。

Linux/macOS/WSLの配布binaryを更新する場合:

```sh
curl -fsSL https://github.com/sahenjp/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windowsは同じReleaseの `install.ps1 -FromRelease` を使用してください。
全変更は [CHANGELOG](https://github.com/sahenjp/rustdsh/blob/main/CHANGELOG.md) に記載しています。
