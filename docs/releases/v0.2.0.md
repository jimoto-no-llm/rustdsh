## 0.2.0 — guarded agent runtime + dashboard/session overhaul

- agent実行をguard化: Linux x86_64 + bubblewrap/prlimit/DSH 0.2.0-rc.2が必須。`--share-file`で共有したファイルだけ読み取り、認証情報の自動取込なし、未対応環境はfail-closed。
- Dashboardに段階更新の互換版固定・run pin、run復元、チェックポイント、再試行制御、モデル照合、preflight診断、費用・予算台帳、質問/返信フロー、スマホoverview、接続診断を追加。
- セッションは永続台帳と再開先の照合を追加。zstdなしで得た `?` をtokenキャッシュに保存しない修正を含む。
- Fixes: インストール・自動更新のSHA256検証、全OS配布物が揃ってからの公開、更新バナーdismiss保持(2時間)。

## 更新前に確認

- **rustdsh経由のagent実行はLinux x86_64のみ対応**。bubblewrap、prlimit、対応するNode.js、DSH **0.2.0-rc.2** が必要です。未対応環境では無保護で実行せず起動を拒否します。macOS・Windows用binaryも配布しますが、agent実行は使えません。
- agentツールは、人間が `--share-file <relative-path>` で共有したファイルだけを読み取れます。秘密情報・ホストへの書き込み・ネットワーク・権限拡大を伴うツール操作は許可しません。隔離内の使い捨て `/tmp` は利用できます。
- 外部Codex/opencodeの認証情報は自動取込しません。必要なら `rdsh auth --import --provider <provider>` で明示的に取り込みます。
- 修正はこのbinaryから起動した新規rustdshプロセスに適用されます。既存プロセスは再起動してください。元DSH・OpenCode・Dashboardの明示的な元CLI直接実行は、このlauncherの保護対象外です。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windowsは同じReleaseの `install.ps1 -FromRelease` を使用してください。
