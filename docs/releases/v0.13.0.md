## 0.13.0 — DSH 0.2.2-alpha.2 への追従と Ollama の effort 補完

- DSH **0.2.2-alpha.2** に対応しました。厳格なツール境界（`features.agent_tool_sandbox` / `RDSH_SECURITY=1`）の監査済みアダプターに `dsh-tools-0.2.2-alpha.2` を追加し、0.2.2 でツールサービスが Cordis 上へ移ったのに合わせて、境界の注入位置をアダプターごとに持つようにしました。
- `rdsh models efforts` を追加しました。Ollama／Ollama Cloud の経路について、`POST /api/show` が返すモデルごとの推論段階を読み、`reasoningEfforts` が無いモデルだけを補完します。手で選んだ一覧は書き換えず、ON/OFF だけのモデル・推論非対応のモデル・取得に失敗したモデルは、段階を推測せず理由付きで報告します（#992）。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 版の判定: minor。`rdsh models efforts` の追加が利用者向けの新機能のため。既存の引数・設定はそのままで、DB や設定の移行は要りません。
- 互換性と移行の要否はこの準備 PR で確定してください。破壊的変更は CHANGELOG とこのノートで必ず明示してください（0.x の間は minor で表現してかまいません）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```
