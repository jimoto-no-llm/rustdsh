## 0.14.1 — モバイル/プラグインを同梱して既定にする

### 追加

- DSH Web UI のモバイル/プラグイン群 `dsh-mobile-maxxing`（kuraneko1、MIT）を同梱し、既定で入れるようにしました。PWA 化、スマホ・タブレット向け UX、アプリ内通知と Web Push、CJK の Markdown 表を提供します。`rdsh-mobile-ui`（Smart-DSH 由来）より後に読み込むため、同じ箇所は `dsh-mobile-maxxing` が優先されます。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 版の判定: patch（dsh-mobile-maxxingの同梱（利用者の明示指示によりpatch））。迷ったら「利用者が新機能として認識するか」を基準にし、この1行は残すか直してください。
- 互換性と移行の要否はこの準備 PR で確定してください。破壊的変更は CHANGELOG とこのノートで必ず明示してください（0.x の間は minor で表現してかまいません）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同じ Release の `install.ps1 -FromRelease` を使用してください。
