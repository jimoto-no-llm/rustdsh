## 0.12.1 — 同梱プラグインの追加と修正

### 追加

- 視覚回答プラグイン（`dsh-intelligent-ui`、cwd514、MIT）を同梱しました。`plugins/install.sh` と `rdsh desktop install` は GitHub から取得せず同梱版を入れ、web/desktop で既定で有効になります。
- `rdsh desktop install` でも、`features.feedback` が明示的にオンでなければメッセージのフィードバック面を無効化する同梱プラグインを入れるようにしました（CLI インストーラと同じ既定）。
- `rdsh features on feedback` で、既に入っているフィードバック無効化プラグインを外すようにしました。

### 修正

- GPUIコンポーザで通常文字が二重入力される問題と、Waylandで通常Enter・Shift+EnterがIME変換中と誤判定される問題を修正しました。
- GPUIデスクトップの既存書式・未使用コード・Clippy警告を整理し、依存proc-macro-error2の公開宣言を修正して将来のRustとの互換性警告を解消しました。
- dsh互換の委譲で非UTF-8を含むPOSIX引数を保持し、nativeコマンドの不正引数でプロセスが異常終了する問題を修正しました。
- computeのtext・max_tokensの型不一致を明示的なエラーで返し、省略時の既定値と後続要求の処理を維持するようにしました。
- スマートフォン幅でrdsh設定本文が狭くなる問題を修正し、既存のモバイルレイアウトを適用しました。
- Windows のアプリ起動は現在の既定ブラウザを使い、対応する Chromium 系ブラウザでは

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。
- 版の判定: 同梱プラグインの追加という新機能を含みますが、依頼により patch として 0.12.1 で公開します。次回以降、同梱プラグインの追加は minor（0.13.0）として扱うのが SemVer に沿います。
- 互換性と移行の要否はこの準備 PR で確定してください。破壊的変更は CHANGELOG とこのノートで必ず明示してください（0.x の間は minor で表現してかまいません）。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

