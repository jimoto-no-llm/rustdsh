## 0.5.1 — モデルカタログ同期の自動化と依存更新

- **モデルカタログ同期の自動化**: 毎日の自動更新（`sync-dsh.sh`）の最後に `rdsh models sync --auto` を追加しました。プロバイダーが公開しているカタログから不足しているモデルを追記し、取得できなかったカタログは失敗として記録しつつ、自動更新そのものは止めません。`rdsh features off models_sync`（既定は on）または1回だけの `RDSH_MODELS_SYNC=0` で無効化でき、`--check-only` と `rdsh` が無い環境では何もしません（`docs/AUTO-UPDATE.md`）。
- **翻訳テストの CI 実行と設定エラー分類**: `translation-core` と `translation-client-crlf` のテストを `ci.yml` の実行対象に加え、無防備だった翻訳まわりを CI で検出します。あわせて、壊れた `rdsh.json` の `SyntaxError` を「読み込めません」ではなく `settings.malformed`（形式が不正）として報告し、README の解決順を実装（`RDSH_LANG` → `general.language` → OS ロケール）に合わせました（#691）。
- **依存関係の更新**: `sha2` を 0.11.1、`plugins/rdsh-mcp-oauth` の `@modelcontextprotocol/client` を 2.3.1 に更新し、GitHub Actions は `dependabot/fetch-metadata` を v3、`pnpm/action-setup` を v6 に更新しました（#685, #686, #687, #688）。
- **インストーラ台帳の更新**: `release-digests.tsv` と `release-digests-windows.tsv` に公開済み v0.5.0 の各アーカイブの SHA-256 を追記し、`latest` 行を v0.5.0 に更新しました。`install.sh --from-release` と自動更新は v0.5.0 を導入します（#690）。
- **リンクチェックの修正**: `.lychee.toml` が lychee 0.24.2 で未知キー `headers` として解析エラーになっていたため、crates.io のクレートページをパターン除外に変更し、構文エラーを解消しました（#689）。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。導入手順は 0.5.0 から変更ありません。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2**、**0.2.1-alpha.1**、**0.2.1-alpha.3** のランタイムを認識）。
- 移行作業は不要です。`rdsh.json` の既存キーや既定値は変わりません。追加された `models_sync` は機能スイッチで、既定は on です。無効化は `rdsh features off models_sync`、1回だけスキップする場合は `RDSH_MODELS_SYNC=0` を使います。
- ソースからビルドする場合は Rust 1.85 以上が必要です（配布バイナリの利用に Rust は不要）。
- モデルカタログの自動同期は `openai-codex` と `kimi-coding` の公開カタログに対応します。取得に失敗した場合も自動更新は成功として終了し、カタログは元のまま残ります。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同リリースの `install.ps1 -FromRelease` を使用してください。
