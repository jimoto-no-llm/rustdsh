## 0.4.0 — 自動更新・診断の拡充とネイティブ化の仕上げ

- **自動更新を1コマンドで有効化**: `rdsh update auto status|on|off` が、実行パスを埋め込んだ systemd ユーザーユニット（日次 + 最大30分のジッター）を生成し、`daemon-reload` と `enable --now` まで行います。更新処理そのものは従来どおり `sync-dsh.sh` が担当します（ダイジェスト固定・ダウングレード拒否・検証・ロールバック）。`dsh` 名で起動したときの `rdsh update` もネイティブ処理に戻り、パスに空白や `%` を含む環境でもタイマーが壊れなくなりました。
- **`rdsh doctor` の診断を拡充**: 壊れた wrapper と影になった `dsh`/`rdsh` を1回の有界スキャンで検出します（dangling symlink、shebang 欠落、消えた `node`/`dsh` 参照、`PATH` 上の重複、`dsh-orig` 不在、`origin` 台帳の不整合）。警告のみで exit status と既存メッセージは変わりません。
- **更新バナーの復活**: Web プロファイルに `rdsh-update-banner` を再び同梱し、更新通知が表示されるようになりました。閉じるボタンと時刻表示の重なりも解消しています。
- **`rdsh serial-proxy` をネイティブ Rust 化**: 常駐 Node.js プロキシを置き換えました。FIFO の同時実行数・レート制限、リクエスト/レスポンスのストリーミング、`--tool-choice-default <none|auto|required>` は維持しています（`docs/SERIAL-PROXY.md`）。
- **配分プランナーを Rust へ移植**: `rdsh subagents plan` は `src/subagent_plan.rs` の実装になり、`rdsh-dashboard subagents plan` はそのまま転送されます。要求・プラン・警告の契約は変わりません（`docs/SUBAGENT-PLANNING.md`）。
- **`rdsh provider add hai|sarashina|local-openai`**: OpenAI 互換ルートをプロファイルの `llm-pi-ai` に追記し、ほかの記述はそのまま残します。`rdsh provider list` でプリセットとプロファイルごとのルート・キー状況を確認できます（`docs/PROVIDERS.md`）。
- **スマホ向け Web UI**: `plugins/rdsh-mobile-ui` を同梱しました。767px 未満でチャットと composer が全幅になり、折りたたみサイドバーはワンタップのロゴ、質問カードは画面内に収まります。
- **Windows インストーラの検証を強化**: `install.ps1 -FromRelease` は配布元のチェックサムではなく、リポジトリの `release-digests-windows.tsv` に固定したダイジェストで Windows アーカイブを検証します。Unix 側の台帳（`release-digests.tsv`）と分離したため、公開済みの `install.sh` が読む形式は変わりません。
- **安全性と同期の修正**: `rdsh-mcp-exposure` の開発依存を修正して high の GHSA-6qxp-vccf-f47h を解消し、`sync-dsh.sh` は `@deepseek-ai/dsh` のツリーを候補順に探索するようになりました（見つからない場合はスキップし、release 更新は止めません）。v0.3.3 のダイジェストを台帳へ固定し、古い版を再固定しても `latest` が過去へ戻らないようにしたので、自動更新が最新リリースを正しく解決します。

## 更新前に確認

- 対応プラットフォームは Linux x86_64（glibc / musl）、macOS arm64・x86_64、Windows x86_64 です。導入手順は 0.3.3 から変更ありません。
- 会話とモデル応答は本家 DSH のままで、互換性は維持されます（DSH **0.2.0-rc.2** と **0.2.1-alpha.1** を認識）。
- 移行作業は不要です。設定は `$DSH_HOME/rdsh.json` のまま、キーや既定値の変更はありません。既存の `rdsh` は同じコマンドで上書き更新できます。
- ソースからビルドする場合は Rust 1.85 以上が必要です（配布バイナリの利用に Rust は不要）。
- `rdsh update auto` は `systemctl --user` が使える Linux のみ対応です。ユニットを設置するだけで、更新処理自体は従来の仕組みを変更しません。
- 既知の制約: `sarashina` プリセットの `tool_choice` 既定は agent 用途では未確定です。`rdsh-mobile-ui` はレスポンシブ表示のみを同梱し、Smart-DSH の通知・Esc 処理・タスクハブは含みません。和訳（#448）と Linux サンドボックス（#254）はこの版に含まれません。
- 更新後は既存の rustdsh プロセスを再起動してください。

Install/update:

```sh
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
```

Windows では同リリースの `install.ps1 -FromRelease` を使用してください。
