## Diagnostic before/after

| Fixture | Before | After |
| --- | --- | --- |
| `doctor --json` | CLI argument error, exit 2 | Schema 1 report, exit 0 or 1 according to prerequisites |
| Nonexistent original override | Selected string treated as discovered | `original.found: false`, exit 1 |
| Original `.js` in a matching Node tree | Plain version probe used PATH Node | Shared runtime selection uses the matching tree |
| Original DSH first, rdsh alias later on PATH | Reported shadowed | First executable match takes precedence |
| Explicit JS launcher plus a comment mentioning dsh | Wrapper warning | No warning; direct `node "$(command -v dsh)"` still produces a hint |
| Two profiles plus a regular README | Counted three entries | Counts two profile directories |
| Three-second version command or inherited stdout pipe | Waited for the full command/pipe lifetime | Omits unavailable version after the two-second probe deadline |

The six initial diagnostic tests all failed before implementation. The expanded
ten-case integration suite passes, including successful plain version output,
missing Node, no credential contents in JSON, no original/Node process launch,
no new settings file, and the inherited-pipe case.
