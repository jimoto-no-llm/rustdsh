## 修正した指摘

| 優先度 | 発生条件と影響 | 修正 |
| --- | --- | --- |
| P1 | 更新用スナップショットが `dashboard/ui/` を含まず、固定された実行環境で `state.mjs` の import が失敗。更新・ロールバック関連の4テストが失敗 | `release-artifacts.mjs` で UI ディレクトリも収集。固定環境からの実 import と改変検出を追加検証 |
| P1 | 長すぎる ID や不正な観測メタデータを持つブロックを文字表示へ変換しても、不正値を保持。保存後の読み込み検証で拒否 | `ui/registry.mjs` と `ui/surface.mjs` で有効な ID とメタデータだけを保存。ID がない変換結果には一意な ID を発行 |

| P2 | `toString`・`constructor`・`__proto__` を許可リストのプロパティとして取得し、未知の操作を既知と判定 | `Object.hasOwn` による登録済みプロパティの確認 |
