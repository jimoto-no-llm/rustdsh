# Rust製フルスクリーンTUI

`native-tui --backend native` は `native-web` と同じRustエンジンを端末から直接操作します。
DSHランタイム、ブラウザー、HTTPサーバーは起動しません。
従来の `rdsh tui` はDSHプロファイルの起動として残ります。

```sh
rdsh native-tui --workspace /absolute/path/to/project \
  --sdk-dir /absolute/path/to/rustdsh/plugins/rdsh-direct-models \
  --dsh-profile web --provider cursor-sdk --model composer-2.5
```

## 画面と操作

上部にワークスペース・モデル・実行状態、中央に会話、下部に複数行入力欄を表示します。
全角文字の画面幅を考慮して折り返し、日本語・結合文字・絵文字を文字単位で編集します。
コードフェンス内の表示を色分けします。nativeモードのモデル応答は生成完了後に表示します。

| キー | 操作 |
| --- | --- |
| Enter | 送信 |
| Alt+Enter / Ctrl+J | 改行 |
| ←→ / ↑↓、Home / End | 入力カーソルの移動、行頭・行末 |
| Ctrl+U | 入力のクリア |
| Ctrl+P / Ctrl+N | 送信履歴を呼び出す（元の下書きを保持） |
| PgUp / PgDn、マウスホイール | 会話スクロール |
| Ctrl+Home / Ctrl+End | 会話の先頭 / 末尾（末尾では新着に追従） |
| F1 | 操作ヘルプ |
| F2 / `/models` | 検索付きモデル選択。↑↓・Enterで選択、Escで戻る |
| F3 | 幅110列以上で実行ログのサイドパネルを開閉 |
| Esc | 画面を閉じる / 実行中止 / 承認拒否 |
| Ctrl+C | 実行中止。待機中は入力をクリア |
| Ctrl+Q / `/quit` | 実行を中止して終了 |

## スラッシュコマンド

入力欄の先頭で `/` を入力すると候補を表示します。入力を続けて絞り込み、
↑↓で選択、Tabで補完、Enterで実行します。Escで候補だけを閉じます。
`/mo` のような途中入力も候補から実行できます。Tabは補完だけで実行しません。

| コマンド | 操作 |
| --- | --- |
| `/help` | 操作方法とコマンド一覧 |
| `/model`、`/models` | 検索付きモデル選択 |
| `/model PROVIDER MODEL` | 指定モデルへ切り替え |
| `/new` | 確認後に会話・送信履歴を初期化。モデルは維持 |
| `/status`、`/usage` | 作業場所、モデル、実行状態、トークン・キャッシュ使用量 |
| `/diagnostics` | 接続診断と利用不可モデルの理由を全文表示 |
| `/logs` | 全実行ログを↑↓・PgUp/Dn・Home/Endで閲覧 |
| `/cancel` | 実行中の処理を中止 |
| `/quit` | 処理を中止して終了 |

実行中はモデル変更・新規会話を拒否します。`/new` の初期選択は「戻る」です。
確認するまで会話を消しません。ファイルや保存済みセッションは変更しません。
未知のコマンド、余分な引数、複数行コマンドはモデルへ送信せず、入力を残して
エラーを表示します。文章を `/` から始める場合は `//` と入力してください。
貼り付けだけではコマンドを実行しません。承認画面には候補を表示しません。

入力上限は16KiB。貼り付け中の改行は送信として扱いません。
通常の貼り付けはBracketed Paste対応端末で利用してください。
42列×14行未満ではサイズ変更の案内を表示し、送信・貼り付け・確認操作を停止します。
縮小前の許可選択も解除します。拡大後は内容を確認して選び直してください。
縮小中もEscで拒否・キャンセル、Ctrl+Cで中止、Ctrl+Qで終了できます。
フルスクリーン、raw mode、マウス入力、Bracketed Pasteは終了時に解除します。

## 承認

ツール要求が来ると、ツール名・理由・引数を専用画面に表示します。
初期選択は**拒否**です。Tab / ←→で「拒否」「一度だけ許可」を選び、Enterで確定します。
↑↓ / PgUp / PgDnで長い引数をスクロールできます。Escは拒否です。
承認画面への文字入力・貼り付けは許可操作になりません。
承認は画面に表示した要求IDに結び付き、期限切れの要求には適用しません。

## 設定と制約

既存 `web` プロファイルの登録モデル・共有済み認証を読み取ります。
認証情報を書き換える機能はありません。SDKモデルでは生成専用アダプターを
使います。推論ループ、ツール実行、承認、キャンセルはRustが所有します。
端末制御文字は表示前に除去し、既知の秘密値は共通エンジンがマスクします。

nativeモードの会話・入力履歴はメモリー内だけに保持し、終了すると失われます。
ディスクへの保存・再開、トークン単位のストリーミングは未対応です。

## 検証

```sh
cargo test --bin rdsh native_harness::tui
# Unix、Node、作業用Python環境のpyteが必要。外部API・実認証を使わない。
python3 tests/native-tui-pty.py /absolute/path/to/rdsh
```

描画バッファで狭幅・通常幅・日本語と各画面、疑似端末でモデル選択、複数行貼り付け、
許可・拒否、キャンセル、サイズ変更、Ctrl+Q / SIGTERM終了後の端末設定復旧を検証します。

## 使用量と他モデル呼び出し

画面下部に実測の入力・出力トークン、キャッシュ読込率、リクエスト数を表示します。
`/usage` で集計対象数、直近の応答時間・Cache Read/Write・reasoning tokenを確認できます。
率はキャッシュ読込トークン ÷ 対応する入力トークン。`*` は取得できた呼び出しの
小計で、未取得の呼び出しを0として混ぜません。SDK等が使用量を返さない場合は
「未取得」です。料金・残り利用枠は推測しません。`/new` で会話単位の集計をリセットします。

主モデルは `model_call {"provider":"登録済みID","model":"登録済みID","prompt":"依頼文"}`
を提案できます。送信先と依頼文を確認し、一回だけ承認してください。相手モデルには
表示した依頼文だけを送り、親の会話履歴やファイルを自動共有しません。相手にツールは
与えず、回答はデータとして主モデルへ返します。拒否・中止時は新しい呼び出しを開始しません。
主モデル、委譲先、JSON修復の再要求をすべて使用量へ含めます。

Rust Web GUIとの機能対応は [NATIVE-PARITY.md](NATIVE-PARITY.md) を参照してください。

## DSHのツール・プラグインを使う

`rdsh native-tui --backend dsh --dsh-profile web --workspace /path/to/project`
で、同じRust画面から既存DSHプロファイルへ接続できます。
操作・接続境界・制限は[DSH接続モード](DSH-TUI-BACKEND.md)を参照してください。
