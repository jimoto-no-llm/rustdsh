rdsh

A launcher for DeepSeek Harness. Frequently used commands are implemented in Rust; conversations and model execution stay in upstream dsh. Existing arguments pass through unchanged.

single binary MIT Linux / macOS / WSL / Windows

Install

curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
$f = Join-Path $env:TEMP 'rdsh-install.ps1'
Invoke-WebRequest -Uri https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.ps1 -OutFile $f -UseBasicParsing
& $f -FromRelease

Running

GoalCommand
Check the installrdsh --version && rdsh doctor
Start the TUIrdsh tui
Web profilerdsh --profile web
Replace dsh./install.sh --as-dsh
Undo the replacement./install.sh --restore

Note

--as-dsh replaces the dsh command with rdsh. The original stays available as dsh-orig, and --restore puts it back.

Reproduce

Run rdsh bench --n 5. Setup and raw data live in docs/BENCHMARKS.md.

How to read it

  • Startup time is the median of five runs on a warm cache.
  • Memory is peak RSS right after start-up.
  • Search, tokens and sessions use the same input on both sides.
  • Distribution size is one binary; upstream is the whole Node.js tree.

Requirement

SAFETY.md

Nothing breaks by default. Risky behaviour is opt-in.

Principles

  1. Upstream fidelityConversation loops and agent logic are never reimplemented; they go straight to dsh.
  2. Non-destructiveRead paths such as tokens, search, sessions and compact never modify source files.
  3. Explicit authCredentials are not sent externally or synced automatically. Only approved items are imported.
  4. Tool sandboxing (opt-in)On Linux, --share-file shows only the files you share, read-only and without network.
  5. Explicit defaultsUpdate checks are on. serve, search-web, context_engine and agent_tool_sandbox are opt-in.

Blocking with a hook

sh
echo "$input" | rdsh guard --deny "rm -rf /*" --deny "*token*"
hooks.json
{ "matcher": "Bash",
  "hooks": [{ "type": "command",
              "command": "rdsh guard --deny \"rm -rf /*\"" }] }

WEB.md

Web UI, dashboard and Desktop app wiring. All of it stays local.

Lightweight status page

A small page bound to localhost (default :38080, no conflict with DSH on :3080). Requests need a one-time token.

sh
rdsh settings set extras.enable serve
rdsh serve

Dashboard

An optional Node.js dashboard (22+) for project metrics and human-in-the-loop questions. On Windows it lives in the system tray.

sh
rdsh-dashboard project --project <directory>

Desktop app

DeepSeek Harness Desktop is an Electron shell around the Web app. It owns a separate profile, so rdsh only detects it and forwards plugin attachment; it never rewrites the profile.

sh
rdsh desktop status
rdsh desktop install --plugins-dir .
rdsh desktop verify

Order

Quit the app before attaching plugins and reopen it afterwards. The in-app Plugins page installs the same packages directly.
