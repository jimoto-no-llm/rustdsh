## 変更内容とIssueの対応

[#52](https://github.com/sahenjp/rustdsh/issues/52)は、正常系のテストだけで全経路を確認済みと誤認しないよう、端末・入力・中断復帰・接続経路を比較できるQA記録を求めている。

| 要求 | 実装と確認 |
| --- | --- |
| 指定経路と未確認項目を一覧・絞り込み | `dashboard/qa`に57セルの定義、JSON検査、HTML生成、状態・端末・操作・経路・証拠水準の絞り込みを追加 |
| 入力中の更新、二度押し、送信中切断を観測 | 実Projectサーバーを使う隔離fixtureで状態更新・送信保留・保存前後の切断を操作。本文保持、POST試行数、保存件数を別々に記録 |
| fixture成功を実接続へ流用しない | fixture・実ブラウザー・実接続を区別。PC表示幅試験をiPhone実機試験へ読み替えず、WSL/Tailscaleを通った証拠を保存 |
| SHA・環境・時刻・証拠を保持 | 各セルに試行の出所を残す。同じ試行のWSL/Tailscale両セルへの対応は明記し、独立試行数として二重集計しない |

検証中に再現したProject dashboardの問題も修正した。

- 同じタブの未送信下書きを再読み込み・戻る操作で復元する。保存できない場合はその制限を表示する。
- 送信中にSSEで画面が更新されても送信をロックする。通信断で結果が不明なときは本文を保持し、保存結果を照合してから必要な場合だけ明示再送できるようにする。
- スマホで回答欄を広く使える配置、コマンド画面の表示範囲、開閉領域、接続・共有の文言を改善する。
- 接続情報がない・古い場合は最新URL/QRで開き直す案内を出す。取得済み内容・下書きを保持し、古いQRを隠す。通常の通信断は認証失効と区別する。

対象はProject dashboardとそのQA機構。DSHのagent loop、回答から生じる実行権限、Rustの委譲経路は変更していない。QAは開発用レポートであり、DSH Harnessの会話・ツール実行画面とは別の入口である。

## 結果の読み方

経路レポートは確認済み53セル、外付けキーボードがなくblockedの4セル、not-run 0セル。これは各時点の証拠を集約した結果であり、最新コードで57セル全部を再実行した数字でも、53回の独立試行数でもない。

旧ブランチではWindowsとWSLのNode v22.23.3でそれぞれ74/74成功し、UI・認証を[追試](verification.md)した。74は旧版の自動テスト件数で、main統合後のテスト件数や実機セル数ではない。統合後の結果は[別記録](current-integration.md)を参照。

main統合後のiPhone・WSL/Tailscale実接続は再試験していない。53 pass／4 blockedは旧版の履歴集計であり、統合後のソースを認定する値として使用しない。

統合後の最終自動テストはWindows／WSLとも263/263成功。PC実ブラウザーで回答復旧・二度押し・切断・認証案内を追試し、最新画像を保存した。WSLの実行条件、既存clippyエラー、E2E終了時の失敗は[統合後の記録](current-integration.md)へ明記している。

既存のレポートには、その時点で未実施だった実機接続・戻る操作が残っている。試験の版・日時・観測値は保持する。公開用コピーでは個人の絶対パスだけを一般化し、原記録はローカルに残す。

## 残る制約

- iPhoneの外付けキーボードでのTab・Enter・Esc/cancelは未実施。PCでのキーボード試験では代用しない。
- QR表示・接続先生成と、別端末での最終QR読み取りは別。後者と全ジェスチャー・回転・VoiceOverの組み合わせは今回の合格範囲に含まない。
- 過去の認証失敗は無効な保存キーという条件を再現し、新しい完全URLでの復旧を確認した。当時の一度の具体的操作順は記録不足で特定していない。
- iPhoneの二度押し試験の一部は「送信保留→SSE→再タップ抑止→利用者の再読み込み→明示再送」。保留解除だけで完了した試験とは扱わない。
- 切断試験は中継fixtureで行った通信障害であり、実際の電波断や完全オフライン動作全体の保証ではない。端末間の下書き同期・完全オフラインは対象外。
- Harnessの接続セルはWeb UIへの到達確認。実際のモデル応答、DSHのagent loop、実Dotトリガーまでの検証とは扱わない。

公開用の証拠には合成データの要約を使用し、個人端末のホスト名・認証URL・ローカル個人パス・実機写真を含めていない。原ログはローカルに保持し、要約の出所と限界を各証拠に記載した。
