# TUI内の管理操作

DSHバックエンドで `/manage` を開きます。`rdsh-tui-admin` は公開APIの型情報のみを提供し、
実行は既存の認証済みHTTP/WebSocket gatewayへ送ります。
設定文書の編集には、このプラグインが提供するoperator限定のRPCを使います。

## 操作

- 名前やnamespaceで検索し、Enterで操作を選びます。F5で一覧を再取得します。
- JSON引数を編集し、Ctrl+Sで確認画面へ進みます。Tabで実行を選んでEnterで送信します。
- 秘密を扱う操作は入力全体をマスクします。管理引数は会話・入力履歴へ保存しません。
- 実行結果は画面に表示します。継続処理はCtrl+Cで中止できます。Escで隠した処理は `/manage` で再表示します。
- uplink対応streamは `i` で入力を編集します。切断した変更要求は自動再送しません。

## ファイル

JSONの値に `{"$file":"相対パス"}` を置くと、指定した通常ファイルをbase64へ変換して送信します。
相対パスはworkspace基準で、絶対パスも明示選択できます。最終要素がシンボリックリンクのファイルと、12MiBを超える入力は拒否します。
binary応答はアクセス制限した一時ファイルに保存し、パスとサイズを表示します。
画像やPDFなどのWebプレビューは `/webui` で開けます。

## 確認すべき結果

HTTP成功だけで設定反映済みとは扱いません。プラグインの `application: failed` は失敗表示し、
`restart-required`、`overridden`、`pendingBuilds` も結果に残します。追加ビルドを自動承認しません。
設定変更はホストのrevision確認を使い、競合時は取得し直して編集します。
継続処理の表示には上限があり、イベントを省略した場合は省略数を表示します。

## 対応範囲

公開RPCは起動中ホストのcatalogから取得します。独自RDSH HTTP操作は明示manifestです。
停止中・未導入のHTTP機能も候補にあり、利用時の通常のHTTPエラーを表示します。
追加プラグインが公開するRPCも型情報があれば一覧へ反映します。

## Web専用画面

`/webui` はDSHと同じ認証済みHostを専用のheadless Chromeで開き、Rust TUI内に表示します。
独自プラグインのJavaScript、フォーム、iframe、canvas、メディアのWeb操作を利用できます。
別ウィンドウや既存の個人ブラウザへ接続しません。Node.jsとChrome/Chromiumが必要です。
ブラウザ実行ファイルは `RDSH_BROWSER_BIN` で指定できます。

- F2で読みやすい文字表示と画像表示を切り替えます。画像表示は端末セルの解像度になります。
- ↑↓/Tabで項目を選択し、Enterで操作します。入力欄はCtrl+Sで値を適用し、空欄への変更にも対応します。
  適用失敗時は編集内容を保持します。16 KiBを超える長文はF3の直接入力とマウスで編集します。
  Web側で無効な項目は「無効」と表示します。F3でWebへキーを直接送ります。
- マウス操作、F5更新、F6タブ切替、Alt+←/→履歴、F7通知・保存ファイルの表示に対応します。
- ファイル選択はTUIのパス入力、ディレクトリ選択もTUI内で行います。
- OSでファイルを開く操作は内部preview、場所の表示は内部フォルダ画面へ接続します。
  native picker構成で一覧APIがない場合は、現在のworkspace内の一覧APIを使います。
- JavaScriptの確認・入力ダイアログはTUIで回答します。Ctrl+]で会話へ戻れます。
- 設定の「設定ファイルを開く」は専用文書エディタで開きます。Ctrl+Sで保存確認、Escで取消です。
  UTF-8・512 KiB上限、リビジョン競合検出、0600バックアップ、atomic保存、適用失敗時の復元を行います。

Chromeとの通信は専用pipeです。認証Cookieは同じHostのみに渡し、ログ・会話履歴へ保存しません。
ブラウザCookieはポート単位に隔離できないため、専用のローカル中継でHTTP/WSの接続先を
起動したDSHのポートに限定します。別ポートの127.0.0.1への直リンクは拒否します。
この中継はOS全体のproxy設定を変更せず、通常の外部Webサイトは直接接続します。
localStorageはDSHプロファイル別のアクセス制限した領域へ保存します。ブラウザ終了時に専用プロセスを停止します。
DSH Web本体が提供していない編集画面が新たに追加されるわけではありません。
presetやMCPの構成は、そのプロファイルの設定画面・設定文書・Creatorが提供する操作を使います。
任意のOSアプリそのものやTUI終了後のOS通知サービスを端末内に移植するものではありません。

## 音声入力

`/record` は録音開始を確認した後、ffmpegでマイクを録音します。Spaceで停止、最長120秒です。
録音はローカルのアクセス制限したWAVへ保存します。Tで送信先を確認して文字起こし、Pでプロバイダを選択します。
転写結果は下書きへ入り、自動送信しません。Esc/Ctrl+]で録音や転写を止めて戻ります。
音声プロバイダの準備と設定は既存のWeb画面または `/manage speech` で行います。

ffmpegは `RDSH_FFMPEG_BIN`、入力デバイスは `RDSH_AUDIO_DEVICE` で指定できます。
macOSはAVFoundation、LinuxはPulseAudio、WindowsはDirectShowを使い、OS側のマイク許可が必要です。
Windowsでは録音デバイス名の明示指定が必要です。録音ファイルは自動削除しません。
