rdsh

dsh を速く起動するランチャーです。

トークン計算や検索は Rust で動きます。会話とモデル実行は本家 dsh にそのまま渡します。

できること

起動が速い

0.90 ms。dsh の 88 ms と比べて 98 分の 1 です。

今の使い方のまま

独自のコマンド以外は dsh にそのまま渡します。

Rust のコマンド

トークン計算、検索、セッション、doctor が Node.js なしで動きます。

ファイルを変えない

読み取り系は書き換えず、認証情報も外に出しません。

該当なし

安全設計

  1. 会話は本家に任せる 会話ループとモデル推論は dsh のままです。
  2. 書き換えない 読み取り系のコマンドはファイルを変更しません。
  3. 認証は明示したものだけ 指定した認証情報しか読みません。
  4. 隔離は任意 Linux では --share-file で共有したファイルだけを渡します。
  5. 既定は OFF serve、search-web、context_engine、agent_tool_sandbox は既定で無効です。

インストール

Linux・macOS・WSL 
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
Windows (PowerShell) 
$f = Join-Path $env:TEMP 'rdsh-install.ps1'
Invoke-WebRequest -Uri https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.ps1 -OutFile $f -UseBasicParsing
& $f
必要なもの
Rust1.85 以上（ソースからビルドする場合）
Node.js22 以上（dsh の実行とダッシュボード）
OSLinux・macOS・Windows・WSL
ライセンスMIT

ソースからは ./install.sh。--as-dsh で dsh を置き換え、--restore で戻せます。
