# packaging

Manifests for the third-party package managers that install the published
macOS and Windows archives. Every file here is generated by
`scripts/update-packaging-manifests.py` and pins one release version, URL and
SHA-256; the digests come from `release-digests.tsv` and
`release-digests-windows.tsv`, so they match what `install.sh` and
`install.ps1` already verify.

| Path | Channel |
| --- | --- |
| `homebrew/rdsh.rb` | Homebrew formula (macOS, Apple Silicon and Intel) |
| `scoop/rdsh.json` | Scoop manifest (Windows x64) |
| `winget/` | winget manifests: version, installer and en-US default locale |

Install commands and the update procedure are documented in
[docs/PACKAGE-MANAGERS.md](../docs/PACKAGE-MANAGERS.md). To refresh every file
after a release is pinned:

```sh
python3 scripts/update-packaging-manifests.py --version vX.Y.Z
python3 scripts/update-packaging-manifests.py --check
```

`tests/test_release_packaging_manifests.py` fails when a committed file drifts
from the generator or from the pinned digest registries.
