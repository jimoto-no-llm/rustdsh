# Support

## Where to ask

| Channel     | Use for                                              |
| ----------- | ---------------------------------------------------- |
| Issues      | Bugs, feature requests and usage questions           |
| Advisories  | Vulnerabilities - see SECURITY.md, never pub issues  |

Japanese is welcome (Japanese OK). The issue forms accept Japanese.

## Before opening an issue

1. Run and paste: rdsh --version, rdsh doctor, OS/shell.
2. Search existing issues first.
3. For delegation bugs, add rdsh --dry-run output plus the expected
   dsh behavior.
4. For UI changes in a PR, attach before/after PNGs (see CONTRIBUTING.md).

## Response expectations

Maintained by volunteers - typical first response is a few days.
Security reports get priority (see SECURITY.md).
