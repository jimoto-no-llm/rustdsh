What it does

Starts fast

0.90 ms, against 88 ms for dsh.

Same commands

Anything that is not a native command goes to dsh.

Rust commands

Token counts, search, sessions and doctor run without Node.js.

Leaves files alone

Read-only commands change nothing and send no credentials.

Safety

  1. Conversations stay upstream The agent loop and model calls are dsh's.
  2. Nothing rewritten Read-only commands leave files untouched.
  3. Only named credentials It reads the credentials you point at.
  4. Sandbox is opt-in On Linux, --share-file passes only the files you share.
  5. Off by default serve, search-web, context_engine and agent_tool_sandbox start disabled.

Install

Linux, macOS, WSL 
curl -fsSL https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.sh | bash -s -- --from-release
Windows (PowerShell) 
$f = Join-Path $env:TEMP 'rdsh-install.ps1'
Invoke-WebRequest -Uri https://github.com/jimoto-no-llm/rustdsh/releases/latest/download/install.ps1 -OutFile $f -UseBasicParsing
& $f
