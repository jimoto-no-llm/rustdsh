# フォルダから始めるファイル整理

DSH Desktop / Webの空の会話画面に、フォルダを選んで整理する入口を追加します。
既存のフォルダ選択機能とGUI認証を使用します。AIへの接続やAPIキーは不要で、分類は端末内で実行します。
空の会話画面にあるプリセット選択の位置がこの入口に切り替わります。プリセットは設定画面から選択できます。
プラグインを無効にすると、標準の入口に戻ります。

1. フォルダを選択する（WebではDSHが動作している端末の場所を入力できます）。
2. ファイル名、分類、件数、必要な容量を確認する。
3. 「確認した内容でコピーする」を押す。
4. 保存先を確認する。必要に応じて「整理を取り消す（コピーを保管）」を押す。

元ファイルは移動や削除をしません。拡張子に応じて写真・資料・表・動画・音声・その他へ分類し、
新しい `rdsh-organized-<id>` フォルダへコピーします。
取り消しを行うと、コピー先全体を隠し保管フォルダ `.rdsh-organize-undone-<id>` へ移動します。
コピーを編集していた場合でも、その内容は保持されます。取り消しを行っても使用容量は減りません。

現在、コピーと取り消しは **Linuxの `/proc/self/fd` が利用できる環境**に対応しています。
Windows・macOSではプレビューのみ利用できます。未対応の環境でパスによる実行へ切り替わることはありません。
対象はフォルダ直下の通常ファイル200件・合計256 MiBまでです。走査は1000項目までとなります。
子フォルダ、隠しファイル、シンボリックリンク、ハードリンクは対象外です。
保存先は非公開ディレクトリ（0700）、コピーは非公開ファイル（0600）として作成します。
写真の撮影日時や内容の認識、PDF要約、Excel加工、GUI自動操作は今後提供予定の機能です。

実行は、サーバー内に保存された確認内容とユーザーによる確認ボタンの操作に基づきます。
確認は10分間有効で、最大4件まで保持されます。ファイルが変更された場合は確認をやり直します。
コピーの途中経過は、保存先の `.rdsh-organize.json` へ記録します。
アプリを再起動した場合は、元のフォルダを再選択することで、前回のコピーを保管したまま取り消せます。
不完全なコピーは自動再開されず、元ファイルと作成途中のコピーを保持します。

このプラグインはPC全体のサンドボックスではありません。
Linuxでは開いたディレクトリハンドルとリンクをたどらない読み込み、排他的な新規作成を使用します。
同じOSユーザーの別プロセスがフォルダを移動・差し替える状況を、完全に隔離するものではありません。
作業中は、選択したフォルダや整理先を別のアプリから変更しないでください。
実データを外部送信するAPIや、モデル向けの実行ツールは公開していません。

```sh
PROFILE=desktop EASY_WORK=1 ./plugins/install.sh
PROFILE=web EASY_WORK=1 ./plugins/install.sh
node --test plugins/rdsh-easy-work/test/*.test.mjs
```

Desktopではアプリのプラグイン画面から、このディレクトリを追加できます。
初期の導線を検証する段階の任意プラグインです。通常のDSH会話・設定画面は引き続き利用できます。
