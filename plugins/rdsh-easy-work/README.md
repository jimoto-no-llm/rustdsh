# フォルダから始めるファイル整理

DSH Desktop / Webの空の会話画面に、フォルダを選んで整理する入口を追加します。
既存のフォルダ選択・GUI認証を使います。AI接続やAPIキーは不要で、分類は端末内で実行します。
空の会話のプリセット選択位置をこの入口に切り替えます。プリセットは設定画面から選択できます。
プラグインを無効にすると標準の入口に戻ります。

1. フォルダを選ぶ（WebではDSHが動いている端末の場所を入力できます）。
2. ファイル名、分類、件数、必要な容量を確認する。
3. 「確認した内容でコピーする」を押す。
4. 保存先を確認する。必要なら「整理を取り消す（コピーを保管）」を押す。

元ファイルは移動・削除しません。写真・資料・表・動画・音声・その他へ拡張子で分類して、
新しい `rdsh-organized-<id>` フォルダへコピーします。
取り消しはコピー先全体を隠し保管フォルダ `.rdsh-organize-undone-<id>` へ移します。
コピーを編集していても、その内容を残します。取り消しで使用容量は減りません。

現在、コピーと取り消しは **Linuxの `/proc/self/fd` が利用できる環境**に対応しています。
Windows・macOSではプレビューのみ利用できます。未対応環境でパスによる実行へ切り替えません。
対象はフォルダ直下の通常ファイル200件・合計256 MiBまで。走査は1000項目までです。
子フォルダ、隠しファイル、シンボリックリンク、ハードリンクは対象外です。
保存先は非公開のディレクトリ（0700）、コピーは非公開ファイル（0600）で作ります。
写真の撮影日・内容の理解、PDF要約、Excel加工、GUI自動操作は今後の機能です。

実行はサーバー内に保存した確認内容と人の確認ボタンに基づきます。
確認は10分間有効、最大4件。ファイルが変わった場合は確認をやり直します。
コピーの途中経過を保存先の `.rdsh-organize.json` へ記録します。
アプリを再起動した場合は、元のフォルダを再選択すると、前回のコピーを保管して取り消せます。
不完全なコピーは自動再開せず、元ファイルと途中のコピーを保持します。

このプラグインはPC全体のサンドボックスではありません。
Linuxでは開いたディレクトリのハンドルとリンクをたどらない読み込み、排他的な新規作成を使います。
同じOSユーザーの別プロセスがフォルダを移動・差し替える状況を、完全に隔離するものではありません。
作業中は選択フォルダと整理先を別のアプリから変更しないでください。
実データを外部送信するAPI・モデル向けの実行ツールは公開していません。

```sh
PROFILE=desktop EASY_WORK=1 ./plugins/install.sh
PROFILE=web EASY_WORK=1 ./plugins/install.sh
node --test plugins/rdsh-easy-work/test/*.test.mjs
```

Desktopではアプリのプラグイン画面から、このディレクトリを追加できます。
最初の導線を検証する段階の任意プラグインです。通常のDSH会話・設定画面は引き続き利用できます。
