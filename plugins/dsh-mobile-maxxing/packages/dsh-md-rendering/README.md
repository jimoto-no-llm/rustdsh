# dsh-md-rendering

DSH のチャット内の Markdown 表に、Project Hub の PWA を参考にした文字サイズ、フォント、余白、罫線、背景、横スクロールを適用する独立プラグインです。**モバイル表示でのみ動作し、PC では React の読み込み・スタイル登録・DOM 変更を一切行いません。**Markdown の解析や表以外の本文、チャット以外のプレビューは変更しません。Project Hub と同様、Markdown で指定した列の揃え方にかかわらず左揃えで表示します。

横スクロールには DSH の既存の表ラッパーを使うため、Project Hub の表本体をスクロールする実装とは異なります。表のセル背景は見出しを含めて同色に統一し、DSH のテーマに合わせます。

## インストール

リポジトリをチェックアウトして、このパッケージの絶対パスを指定します。

```sh
dsh plugin --profile web add "$(pwd)/packages/dsh-md-rendering"
```

独立したバンドルとしてインストールされ、モバイル本体がなくても利用できます。本体がある場合はその端末判定を優先し、ない場合は端末情報から判定します。無効化または削除すると標準の表示に戻ります。画面への反映には再読み込みが必要な場合があります。

DSH の表・チャットの DOM 構造に依存するため、DSH の更新後は表示を確認してください。
