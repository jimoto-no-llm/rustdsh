# dsh-mobile-maxxing v1.0.0 リリースノート

公開日: 2026-10-28

モバイル本体・Markdown 表・日本語化を独立した3コンポーネントのまま、通知の信頼性、モバイル操作性、単体導入時の動作、配布の安全性を改善した正式リリースです。

## 主な変更

### 通知・PWA

- モバイル送信を requestId と実際のユーザーメッセージで対応付け、通信遅延時に別ターンや別端末の通知へ付け替わる問題を修正しました。
- 同じ User-Agent の別端末や、しばらく使っていない端末の購読を誤って削除しないようにしました。
- 端末ごとの Push 配信を並列化し、10秒の送信期限を設定しました。一つの遅い endpoint が他の端末を止めないようにしています。
- 明示的に通知を有効にした端末では、購読が失われた場合に起動・オンライン復帰・可視化時の再登録を行います。通知の有効化と無効化が同時に起きた場合の競合も防ぎます。
- 公開 origin と待機中の送信識別子をプロファイル別に保存し、再起動後の通知落ちとプロファイル間の混線を防ぎます。
- Push endpoint は HTTPS に限定し、DNS の全回答を検証して検証済みアドレスへ接続します。リダイレクトは追跡せず、内部ネットワークへの POST を防ぎます。

### モバイル UI

- 質問カードを削除したりプラグインを無効化したりした後もイベントリスナーが残る問題を修正しました。
- タブレット横向きのヘッダーとパネルタブ、短い画面での更新操作、コマンド編集中のフォーカスを改善しました。
- ツール要約の配置、Bash プレビューの折り返し、選択済みコマンドチップの削除を改善しました。
- アプリやセッションを開いたときの自動フォーカスを抑止し、キーボード表示中の操作を安定させました。
- フォークしたルートセッションを含む完了通知と、質問の回答・通知アクションの配置を改善しました。

### Markdown 表・日本語化

- Markdown 表プラグインがモバイル本体なしの単体インストールでも端末を判定して動作するようにしました。
- 明示された desktop / mobile モードを優先し、PC では React の読み込みとスタイル登録を行いません。
- 日本語化は65名前空間・2915キーを翻訳し、英語フォールバックなしで配布します。DSH 0.2.1-rc.2 / rc.3 の peer 依存を整合させました。

### インストール・リリース

- 従来の1つのインストール用URLを維持し、3コンポーネントを個別に有効・無効にできます。
- リリースには今回生成した4成果物だけを添付します。旧成果物は dist/ に保持したまま、誤って新リリースへ混入させません。
- パッキング失敗時は既存成果物と README を復旧します。空白を含むチェックアウトパスにも対応しています。
