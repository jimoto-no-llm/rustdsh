# dsh-mobile-maxxing v1.0.2 リリースノート

公開日: 2026-11-06

v1.0.1 のあとに届いた実機報告への対応と、モバイルの動作を軽くする変更をまとめた修正リリースです。

## 主な変更

### iOS の端スワイプで画面が戻る退行（#139）

1.0.1 で入れた戻り操作の統一が、iOS でも履歴に番兵エントリを積んでいました。Safari / PWA の**画面端スワイプは OS が履歴を戻す**ため、その番兵が外れてアプリ内の戻る（ホーム移動）が走っていました。

- 履歴ガードは **Android の戻るキーだけ**に限定しました。iOS の端スワイプはアプリ内のドロワー操作として扱います。
- 画面左端 28px 以内のタッチで OS のジェスチャーを打ち消し、アプリ内のスワイプに一本化します。

### キーボード回避が DSH 0.2.2 で一度も動いていなかった

DSH 0.2.2 では**アプリのシェル自体が `role="dialog"`** です。そのため「ダイアログが開いていたら何もしない」という既存のガードが常に成立し、キーボード回避・safe-area 計測がブラウザでも PWA でも実行されていませんでした。シェルの上に開いたモーダル（設定・ディレクトリピッカー）だけを除外するよう修正しました。

### 右パネルを開いていると、左端スワイプでセッション一覧が開く（#113）

「ドッキング（横並び）」の判定を**幅の比率（85%）**で行っていたため、画面幅より少し狭いパネルが横並びと誤判定され、左端がドロワーのものになっていました。

- 判定を**パネルの左端の位置**に変更しました。左端から始まるシートは、幅が狭くてもパネルが左端を所有します。
- 開閉マーカーの反映遅れに備え、アプリ側の印とタッチ位置からも判定します。

### 動作の軽量化（#140）

パフォーマンスレビューで実測した効果の大きい4点を入れました。

- **decorate をストリーミング中だけ 120ms 間引き**。実測で main-thread の JS が 1001ms → 83ms / 3秒（−92%）。条件によって decorate が永久に止まる不具合も修正しました。
- **safe-area の計測を必要なときだけに**。キーボード表示中は計測せず、幾何が変わらなければスキップします（実測 7.0〜7.7ms/回）。
- **スワイプ中のスクロール祖先探索を1回に**。getComputedStyle が指1move あたり 11.2 回走っていました。
- **LiveSpeed のポーリングを生成中だけに**。アイドルでも 0.5 秒ごと（7,200 リクエスト/時）走っていたものを、生成中 500ms・停止中 5秒にしました。

## 検証

- テスト: **766 / 752 pass / 0 fail / 14 skipped**、日本語化 41/41
- 環境: DSH 0.2.2-rc.1 + iPhone（Safari / ホーム画面アプリ）

## 既知の制限

- ターミナルの幅が変わるとき、bash の再描画（SIGWINCH）でプロンプト行が一瞬二重に見えることがあります。xterm 側ではなくシェル側の再描画によるものです。
