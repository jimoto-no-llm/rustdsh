# dsh-mobile-maxxing v1.0.4 リリースノート

公開日: 2026-11-06

セッションタイトルの位置、更新パネルの情報量、更新完了表示の3点を改善しました。

## 主な変更

### セッションタイトルの位置（#145）

モバイルのヘッダーは、サイドバーのトグル用に左 64px を空けており、スマホではそのトグルがドロワーなので**その帯が空いたまま**でした。タイトルはその内側に置かれるため、画面中央より左へ約 32px ずれていました。

- タイトル行の内側パディングを外し、余白を左右の自動マージンで分配することで**画面中央に配置**しました（実測: 中心 163px → 184px / 画面中心 195px）
- ヘッダー自体のパディングは変えていません。狭めるとタブ行が詰まり「軌跡」が「…」に隠れるためです
- 長いタイトルは折り返さず、はみ出しはアプリ側の省略に任せます

### 更新タブにバージョンを表示

「更新」タブを開いた時点で、**Mobile Maxxing プラグインのバージョン**と**DSH 本体のバージョン**を表示します。GitHub への問い合わせなしで返す軽量ルート（`?local=1`）を使うため、開いた瞬間に出ます。

### 更新完了の表示が消えないように

更新が完了すると、プラグインの差し替えで画面が再マウントされ、**完了ダイアログが読む前に消えていました**。完了状態を `sessionStorage` に保存し、再マウント後も「更新完了」を表示したままにしました。閉じるのはユーザーが「閉じる」を押したときだけです。
