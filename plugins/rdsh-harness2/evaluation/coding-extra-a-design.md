# 追加課題 A の設計

実モデル実行前に仕様・公開テスト・非公開テストを固定する追加 holdout 3 課題。`coding-extra-a.json` は `version/name/tasks` の断片で、主比較スイートの training 課題と結合して使う。各課題は編集可能な依存なし ES module 2 ファイル、変更不可の公開テスト 2 件、採用後に実行する非公開テスト 10 件を持つ。

| 課題 | 明示した境界・アルゴリズム | 初期 公開 PASS/FAIL | 初期 非公開 PASS/FAIL | 参照 公開・非公開 |
| --- | --- | ---: | ---: | ---: |
| `half-open-range-difference` | 半開区間、接する区間の統合、分割・複数穴、除去集合の正規化、有限小数、未使用入力も検証、凍結入力・返却配列の独立 | 1/1 | 2/8 | 2/2・10/10 |
| `incremental-delimiter-framing` | 複数文字の区切りとチャンク跨ぎ、非重複の左優先消費、空フレーム、区切り部分一致を除外する保留長上限、finish での部分一致再評価、UTF-16 長、終了状態 | 1/1 | 5/5 | 2/2・10/10 |
| `layered-config-merge` | 再帰的な階層マージ、配列の全置換、falsey/null/undefined と DELETE、再作成、継承キー無視、全深度コピー、無効値の早期検証、凍結入力 | 1/1 | 3/7 | 2/2・10/10 |

非公開テストは各 10 件の平坦な `node:test` ケース。制御された promise タイミングや実時間待ちに依存しない。参照実装はモデル可視の fixture や公開ソースへ保存しない。JSON 断片に解答は含めない。

検証は production `grade-coding.mjs` を使用し、macOS `sandbox-exec` と `pure-esm-fixture-v1` のソースポリシーも通した。初期実装および一時参照実装について公開・非公開を独立に 12 回実行し、上表を確認した。参照の合計は公開 6/6、非公開 30/30。これは実装可能性と fixture の確認であり、実モデルの成績ではない。

特殊なキー名を文字列で列挙する要件は設けていない。評価用ソースポリシーが直接の実行環境・採点 API への参照を制限するため、一般の敵対的 JavaScript を受け入れる隔離評価ではない。
