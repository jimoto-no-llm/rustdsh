ログインして使う

端末でログインした後、rdsh auth でプロバイダーIDを確認します。使うものだけ取り込み、「接続状況を更新」を押してください。

opencode auth login
codex login

ログイン後の取り込み: rdsh auth --import --provider <id>。Codexの場合は次のコマンドを使います。

rdsh auth --import --provider openai-codex --source codex

APIキーを保存する

この端末のDSH設定に保存します。APIキーはサブスクリプションのログインとは別です。新規の接続先はDSHの「Settings → Models」でAPIキーと一緒に追加できます。
